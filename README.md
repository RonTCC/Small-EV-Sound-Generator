# Small-EV-Sound-Generator
A super-simple sound generator for small EVs (ex. UTV)

Introducing an adjustable Sound Generator for your (EV)UTV.

If you use your UTV primarily off-road, you can safely ignore this system.

We, however, use our (EV)UTV in campground settings with a lot of "middle of the road" walkers.
While slightly amusing, I thought it kind of rude to sneak up on people with the EV.

Thus, I decided to use a spare Arduino to create an adjustable sound generator.  

I tried a lot of sound algorithms. However, nothing sounded better than my Honda CR-V Hybrid sound. So, this Arduino sketch uses an imbedded recording of that sound.
